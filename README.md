# Головы местами — локальное приложение для Windows

Нативное окно на русском. Нейросеть переносит лицо, волосы и форму головы.
Работает с фотографиями и нарисованными персонажами. Ключи API и подписка не нужны.

## Запуск

1. При первой установке запусти **Install.cmd**. Нужны интернет и около 20 ГБ
   свободного места: Python, PyTorch CUDA, библиотеки и примерно 5,2 ГБ моделей.
   Установка хранится внутри этой папки и не меняет системный Python.
   Большие файлы скачиваются частями с докачкой и проверкой SHA-256.
2. Открывай **Start.cmd**. После установки интернет не требуется.
   Также можно перетащить файл фотографии на **Start.cmd**.
3. Для обмена на одном фото открой снимок и обведи две головы — сначала А, затем Б.
   Включи волосы, уши, подбородок и немного пространства для новой формы головы.
   Правая кнопка мыши отменяет последнее выделение.
4. Нажми **Поменять головы**. Сравни исходник и результат, сохрани PNG.
5. Для переноса с другого снимка выбери **Голова с другого фото**, выдели одну
   голову на основном фото и загрузи крупный портрет человека или персонажа.

## Что сохраняется

Размер исходного изображения сохраняется. Пиксели **вне выделенных прямоугольников**
берутся из исходника без изменений. Внутри выделения нейросеть может изменить
и окружающие голову детали, поэтому выделять слишком большую область не стоит.
Оставляй место для новой причёски и нового контура. Шея и плечи видны модели
как контекст, но вне выделения не перерисовываются.

Это генеративная замена: точное сходство, выражение, поворот головы и отсутствие
артефактов не гарантируются. Для сложных ракурсов попробуй другой вариант.
Модель вычисляет 4 шага на каждую голову; обмен в обе стороны — два отдельных прохода.
«512»/«768» — размер обрабатываемого фрагмента, а не размер всего сохранённого фото.
Приложение восстанавливает размер фрагмента при вклейке, это не добавляет реальной детализации.

## Локальная обработка и оборудование

Фотографии не отправляются на сервер. Во время обработки включён offline-режим
Hugging Face, облачных проверок изображений нет. Это не обещание, что нейросеть
корректно обработает абсолютно любой сюжет.

Расчёт рассчитан на NVIDIA с CUDA, с переносом частей модели в оперативную память.
Для RTX 2060 используется FP16 вместо неподдерживаемого BF16 и NF4-квантизация весов.
Начни с «Быстро · 512». При нехватке памяти закрой игры и Unity.
Модель остаётся загруженной между обработками; закрытие приложения освобождает память.
Отмена и закрытие во время работы завершаются после текущего этапа модели.

На RTX 2060 6 ГБ проверочный обмен двух голов в режиме 512 занял около 42 секунд
вместе с загрузкой модели; пиковое использование нейросетью — примерно 3,7 ГиБ
видеопамяти. Скорость зависит от размеров выделений и нагрузки компьютера.
Проверочный рисунок с двумя персонажами обрабатывался около двух минут.
На однотонных фонах приложение дополнительно выравнивает оттенок вокруг головы,
чтобы уменьшить заметность прямоугольной области обработки.

Модели скачиваются в `models/`, Python и библиотеки — в `.runtime/` и `.venv/`.
Исходники фото не копируются в папку приложения. Результат сохраняется только
после выбора пути пользователем. Диагностика ошибок — `logs/app.log`.

Автозапуска и фоновой службы нет. Для удаления закрой приложение и удали всю
папку `HeadSwap`: вместе с ней удалятся Python, библиотеки и модели приложения.

## Использованные модели

- [FLUX.2 Klein 4B](https://huggingface.co/black-forest-labs/FLUX.2-klein-4B), Apache 2.0.
- [Готовая NF4-квантизация](https://huggingface.co/hlhc/FLUX.2-klein-4B-bnb-4bit)
  (веса safetensors, без исполнения кода из репозитория).
- [BFS Head V1 для Klein 4B](https://huggingface.co/Alissonerdx/BFS-Best-Face-Swap), MIT.

Версия базовых весов закреплена; версия LoRA записывается при установке в
`models/ready.json`. Сторонние модели распространяются по собственным лицензиям.
